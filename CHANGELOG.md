# История версий

## 1.0.4 — исправление автообновления exe

- Исправлено: обновление exe-версии не могло установиться — запущенный Beseda.exe не может перезаписать сам себя (Windows блокирует файлы работающей программы). Теперь установку выполняет служебный .bat: ждёт выхода программы, копирует файлы с откатом при ошибке и запускает программу снова
- **Важно:** эта версия ставится вручную поверх предыдущей (обновлятор 1.0.2–1.0.3 сам себя обновить не может). Все следующие версии будут обновляться из приложения как положено

## 1.0.3 — трей, обслуживание сервера из админки

Клиент:
- Закрытие окна сворачивает «Беседу» в трей — программа продолжает работать (голос, уведомления). Полный выход — меню значка в трее → «Выход»

Сервер и админка:
- Настройки → «Файлы»: максимальный размер загружаемого файла меняется из админки, без перезапуска
- Настройки → «Сервер»: кнопки «Перезагрузить сервер» и «Проверить обновления» / «Обновить сейчас» (через update-watch.sh на сервере)
- Настройки → «Резервные копии»: создание, скачивание и удаление бэкапов базы и файлов из браузера
- Исправлено: меню «Действия» в списке пользователей обрезалось таблицей
- Версия сервера теперь совпадает с версией продукта (тегами репозитория)

## 1.0.2 — обновления для exe-версии

- Клиент, собранный в Beseda.exe, теперь тоже обновляется из приложения: в релизах публикуется архив `client-*.zip`, обновлятор сам заменяет файлы программы после закрытия
- exe принимает служебные команды: `Beseda.exe --check` и `Beseda.exe --update`

## 1.0.1 — исправление ошибок

- Исправлено: ошибка `AttributeError: 'Api' object has no attribute 'insecure'` при открытии настроек (⚙), вкладка «Профиль»
- В настройках профиля статус соединения теперь различает: обычный HTTP, самоподписанный сертификат и нормальный HTTPS

## 1.0.0 — первая публичная версия

- Текстовые каналы: серверы с приглашениями, история с подгрузкой, правка/удаление, @упоминания, «печатает…»
- Файлы до 50 МБ, картинки в чате, скриншоты по Ctrl+V, drag&drop
- Голосовые каналы: Opus 48 кГц с FEC, шифрование ChaCha20-Poly1305, джиттер-буфер, VAD, PTT, громкость каждого собеседника
- Веб-админка `/admin`: пользователи, серверы, голос, сообщения, файлы, настройки, журнал
- Развёртывание сервера: Docker (Caddy, автоматический HTTPS) или install.sh для Ubuntu
- Клиент Windows: PySide6, трей, уведомления, автопереподключение к голосу
- Автообновление клиента из репозитория GitHub (кнопка версии внизу списка каналов)
